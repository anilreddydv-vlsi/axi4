Transaction, transfer, burst, beat

These four words get mixed up in interviews. Pick a word and the diagram highlights exactly what it covers. The beat count follows the simulator above.

TermWhat it isHow many in one transactionMarked by
TransactionThe complete operation: address handshake, all data, and (for writes) the response1Starts at AW/AR (or leading W data), ends at B or the RLAST beat
BurstThe run of data beats generated from one start address, described by AxLEN, AxSIZE and AxBURST. Often used to mean the whole transaction1AxLEN + 1 beats
TransferAny single VALID/READY handshake, on any of the five channelsWrite: AxLEN + 3. Read: AxLEN + 2VALID and READY high on a rising ACLK edge
BeatOne data transfer inside the burst. Every beat is a transfer; not every transfer is a beatAxLEN + 1WVALID/WREADY or RVALID/RREADY; the last one has WLAST/RLAST

FIXED2'b00Same as the start address on every beat1 to 16Any; the same byte lanes repeat every beatFIFO or data register in a peripheral
INCR2'b01Beat 0 = start; then aligned start + N × size1 to 256 (AXI4), 1 to 16 (AXI3)Any; only beat 0 can be partial. Must not cross 4 KBMemory, DMA block copies
WRAP2'b10Like INCR, but jumps back to the wrap boundary at the top of the window2, 4, 8 or 16 onlyMust be aligned to the sizeCache line fill, critical word first
Reserved2'b11Never used. A master must not issue it

WRAP window: window size = beats × bytes per beat; wrap boundary = start rounded down to a multiple of the window size. A 4-beat, 4-byte WRAP from 0x38 has a 16-byte window at 0x30–0x3F, so the beats go 0x38, 0x3C, 0x30, 0x34.

Check yourself

DV corner: check it and model it

Burst rules are worth assertions on the AW and AR channels, and your monitor or slave model needs the same address formula the simulator uses.

Protocol assertions (write side)

// Reserved burst type is never driven
a_no_rsvd: assert property (@(posedge aclk) disable iff (!aresetn)
  awvalid |-> awburst != 2'b11);

// FIXED: at most 16 beats
a_fixed_len: assert property (@(posedge aclk) disable iff (!aresetn)
  (awvalid && awburst == 2'b00) |-> awlen <= 8'd15);

// WRAP: length 2, 4, 8 or 16
a_wrap_len: assert property (@(posedge aclk) disable iff (!aresetn)
  (awvalid && awburst == 2'b10) |-> awlen inside {1, 3, 7, 15});

// WRAP: start address aligned to the transfer size
a_wrap_align: assert property (@(posedge aclk) disable iff (!aresetn)
  (awvalid && awburst == 2'b10) |->
    (awaddr & ((1 << awsize) - 1)) == 0);

// Size never wider than the data bus
a_size: assert property (@(posedge aclk) disable iff (!aresetn)
  awvalid |-> (1 << awsize) <= DATA_W/8);

Beat address function for a monitor or slave model

function automatic logic [31:0] beat_addr(
    logic [31:0] start, logic [7:0] len,
    logic [2:0] size, logic [1:0] burst, int n);
  int unsigned nb    = 1 << size;
  int unsigned total = nb * (len + 1);
  logic [31:0] aligned = (start / nb) * nb;
  logic [31:0] wb      = (start / total) * total;
  if (n == 0 || burst == 2'b00) return start;   // beat 0 or FIXED
  if (burst == 2'b01) return aligned + n * nb;  // INCR
  return wb + ((aligned - wb + n * nb) % total); // WRAP
endfunction

// Byte lanes used by beat n (DBB = DATA_W/8)
// lower = addr - (addr / DBB) * DBB
// upper = (n == 0 || FIXED) ? aligned_start + nb - 1 - (addr / DBB) * DBB
//                           : lower + nb - 1

Coverage worth having

Cross AxBURST × AxLEN (1, 2, 4, 8, 16, 17, 256) × AxSIZE, plus unaligned starts on INCR and FIXED, narrow transfers (size smaller than the bus), WRAP starting at every position inside its window, and INCR bursts that end exactly on a 4 KB boundary.
