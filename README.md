# AXI4 Interactive Series

Five interactive pages for learning the AMBA AXI4 protocol, by Anil Reddy Tatigotla.

| Page | File |
|---|---|
| Home | `index.html` |
| 1. AXI4 basics | `basics.html` |
| 2. FIXED burst | `burst.html#fixed` |
| 3. INCR burst | `burst.html#incr` |
| 4. WRAP burst | `burst.html#wrap` |
| 5. 4 KB boundary | `4kb-boundary.html` |

Plain HTML, CSS and JavaScript with no build step. To publish: push these files to a GitHub repository, then enable **Settings → Pages → Deploy from a branch** (root folder).
